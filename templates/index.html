ARCHITECTURE

How It Works

1. Preprocessing & Normalization

Cleanses raw input text by stripping HTML tags, removing non-standard punctuation, and normalizing whitespace while retaining structural signals such as capitalization density and currency symbols.

2. FeatureUnion Matrix Construction

Combines sublinear TF-IDF vectorization (1-2 N-Grams) with direct heuristic signal arrays (urgency score, link count, capitalization density) into a unified high-dimensional feature set.

3. Heuristic Signal Extraction

Extracts domain-specific threat indicators including suspicious domain links, urgency keywords (e.g., "IMMEDIATE ACTION"), call-to-action density, and financial triggers.

4. Naïve Bayes Classification

Calculates relative log-probabilities across combined features to compute real-time spam and authenticity confidence scores in under 15 milliseconds.

Pipeline Specifications

  • Algorithm: Multinomial Naïve Bayes with Laplace Smoothing ($\alpha = 1.0$)
  • Vectorizer: Sublinear TF-IDF (Unigrams + Bigrams, $N \in [1, 2]$)
  • Training Corpus: 15,000+ curated spam and ham text samples
  • Average Inference Latency: ~12.4ms per request

OVERVIEW

About Project

Authentiq AI is engineered for high-accuracy text analysis, targeting spam, deceptive content, and phishing attacks in real time. Built specifically for high-throughput public safety and content moderation workflows, it combines fast statistical machine learning with targeted heuristic signal detection.

Key Capabilities

  • Detects phishing attempts, lottery scams, and promotional spam in milliseconds.
  • Identifies key linguistic risk markers like artificial urgency, suspicious links, and manipulative phrasing.
  • Provides local session audit history with JSON export capabilities for compliance and review.
